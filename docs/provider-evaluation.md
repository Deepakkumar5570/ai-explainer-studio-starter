# Provider evaluation checklist

Test the same 30–60 second Hindi script across candidate providers.

Score each from 1–5:
- Hindi pronunciation (names, English technical terms, Devanagari)
- Natural cadence and pauses
- Generation latency
- Audio quality
- Voice consistency
- Commercial-use terms
- Price per finished minute
- Failure rate and retry behavior

Do not choose a voice provider from demos alone. Listen to actual generated audio from your intended content domains before committing.
